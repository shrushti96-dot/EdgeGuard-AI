## 📋 Executive Summary

Unplanned industrial machinery downtime costs discrete and process manufacturing facilities hundreds of billions of dollars annually. **EdgeGuard AI** is an end-to-end industrial digital twin and predictive maintenance system that bridges **Cloud AI training (Microsoft Azure ML)** with **Autonomous On-Premises Edge Inference (Azure IoT Edge)**.

The platform provides factory operators, maintenance technicians, and reliability engineers with a **3D WebGL Digital Twin** of a multi-machine factory floor. Telemetry generated by simulated IoT sensor streams is ingested and scored by an authenticated **Random Forest** predictive maintenance model running with **sub-millisecond latency (< 1 ms)**, guaranteeing continuous protection even under total cloud network disconnects.

## ⚡ Features & Capabilities

- **Real-Time Simulation Controls**: `Step Sim (+1)`, `Auto-Stream (2s)`, `Reset Sim`, `Inject Fault`, and `Clear Fault`.
- **Tri-State Status System**:
  - 🟢 **Normal**: Risk < 32%, all physics setpoints nominal.
  - 🟡 **Warning**: Risk 32%–50% or approaching physical threshold boundaries.
  - 🔴 **Critical**: Risk ≥ 50% or safety limits breached (triggering flashing 3D beacons and audio-visual cues).
- **Physical Safety Rules vs. ML Inference**: Clearly distinguishes between probabilistic statistical model inference and deterministic engineering threshold violations (e.g. Process Temp > 46.5°C, Torque > 68 Nm).
- **SCADA Analytics Suite**: Interactive Plotly multi-axis time-series charts, 6-machine fleet health distribution donut chart, feature influence attribution, and timestamped CSV export.
- **Azure ML Cloud Integration**: Built-in support for Azure Machine Learning Model Registry (SDK v2) with zero-crash fallback to autonomous local edge mode when credentials are not configured.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 to 3.14
- Operating System: Windows, macOS, or Linux

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/EdgeGuard-AI.git
   cd EdgeGuard-AI
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the Application:**
   ```bash
   python -m streamlit run app.py
   ```
   *(If port 8501 is occupied, launch on an alternative port: `python -m streamlit run app.py --server.port 8502`)*

4. **Access the Dashboard:**
   Open [http://localhost:8501](http://localhost:8501) (or `http://localhost:8502`) in your browser.
